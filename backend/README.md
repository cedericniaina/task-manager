# TASK-MANAGER

## FOR DEV

- L'**index.php** contient les routes de l'api
- Le **request.php** c'est la class parent pour insere les donne et qui communique avec database.php (Les autre fichier *.php dans ce fichier sont des heritages de request.php)
- Le **database.php** contient tous les connection avec la base de donne.
